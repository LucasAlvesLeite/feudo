# QuantumComputing

Esta fazenda é uma que foi nutrida durante minha graduação, em minha Iniciação Cientifica.

Usei bibliotecas como Qiskit e Pennylane para poder trabalhar com simulação eletronica (AbInitio) de moléculas, eventualmente chegando a tratar, com algumas aproximações, a molécula de CO2, tão importante para áreas como materiais, bio-energias, farmaceutica, entre outras.

## O que você encontrará aqui:

- **Active Space**: Tratamento do espaço de ligação dos átomos, aqui tratamos uma das otimizações que deram frutos relevantes para a praticalidade da simulação.
- **Adapt VQE**: Aqui estudo o uso de algumas ferramentas que melhoram a solução da equação que foi simulada para as moléculas.
- **Otimizadores**: Creio ser autoexplicativo o nome deste estudo, estamos buscando uma diminuição na complexidade e no tempo de simulação.
- **Mapeadores**: Outro ponto relativo as simplificações de representação buscando diminuição na complexidade.
- **CO2**: Cuminância dos estudos feitos acima e a aplicação para uma molécula dificil matematicamente dificil de ser tratada e simulada com precisão.
