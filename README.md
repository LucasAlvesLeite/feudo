# Feudo 

Meu reino de código. Uma coleção viva de projetos, ideias e experimentos - alguns residem aqui, outros cresceram e conquistaram seus próprios territórios (repos separados).

## Sobre este Espaço

Este repositório é onde minhas ideias ganham forma e código. Funciona como um laboratório pessoal onde testo conceitos, implemento soluções, e documento minha jornada de aprendizado. Não espere perfeição - espere evolução.

### O que você encontrará aqui:

- **Experimentos**: Testes rápidos, provas de conceito, e "será que isso funciona?"
- **Projetos em desenvolvimento**: Trabalhos que ainda estão ganhando vida
- **Estudos práticos**: Implementações de conceitos que estou aprendendo
- **Ferramentas pessoais**: Scripts e utilidades que criei para resolver problemas do dia a dia

### Estrutura

Cada pasta representa um projeto ou área de interesse. Alguns são rascunhos de uma tarde, outros são fundações para algo maior. Os projetos que amadureceram o suficiente podem eventualmente migrar para seus próprios repositórios - este é o berço deles.

### Navegação

Explore livremente. Cada projeto possui sua própria documentação (quando aplicável). Se algo te interessar ou você tiver sugestões, fique à vontade para abrir uma issue ou contribuir.
